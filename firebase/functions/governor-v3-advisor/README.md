# Советник семинара 7

Firebase Function `governorV3Advisor` принимает JSON POST с проверенным Firebase ID token. Поддерживается origin опубликованной платформы. Loopback разрешён в тестовом проекте `demo-*` при локальных Auth и RTDB. Сервер сверяет канонический учебный профиль и UID. `studentKey: null` разрешён преподавателю по той же серверной проверке, что и в «Обращениях граждан». Привязка случайного ID попытки к тому же владельцу проверяется при каждом обращении. Гостям доступна локальная справка.

На вход поступают `requestId`, `attemptId`, `studentKey`, `year`, `revision`, `language`, `question` и `facts`. В `facts` разрешены денежные поля текущего бюджета, три налоговых варианта, проверяемые численные сведения о разрешённых площадках и один маршрут. Поле `gameContext` может содержать до 12 строк о текущей игре, до 600 знаков на строку и 3600 знаков в сумме. Поле `history` может содержать до трёх предшествующих пар `{question, answer}`, до 600 знаков на вопрос и 900 на ответ.

Модель получает вопрос, год, язык, игровые факты, контекст и краткую историю. Перед отправкой сервер заменяет обнаруженные адреса электронной почты, телефоны, учётные номера, идентификаторы и секреты. Ответы должны опираться на доступные сведения об игре и помогать игроку разобраться в вариантах. Игрок принимает и подтверждает решения сам.

Успешный ответ имеет поля `{intent, answer, model}`. `answer` содержит готовую текстовую реплику, `model` содержит `gpt-6.1-terra`. Поле `intent` предлагает клиенту подходящий переход и принимает `tax`, `sites`, `loan`, `budget`, `route`, `compare`, `event` или `unknown`. Модель отвечает и на вопросы без подходящего перехода. Код `409` означает параллельный запрос или конфликт повторного идентификатора. После закрытия повтор возвращает тот же ответ. Ошибка при ожидании ответа провайдера завершает этот идентификатор и исключает повторный вызов.

Закрытая область RTDB находится по пути `rudn-platform/v1/governorV3Advisor`. Она содержит хэш владельца, хэши идентификаторов, контрольную сумму запроса, отметки времени, этап запроса и очищенный ответ для безопасного повтора. Исходный вопрос, контекст и история не записываются в квотное хранилище и серверный лог. Верхние пределы составляют 50 обращений на попытку, 16 на UID в день и 240 на проект в день. Прерванный запрос может остаться в состоянии ожидания. Его повтор использует локальную подсказку при получении `409`. Учебная запись и состояние партии обрабатываются отдельным штатным контуром.

Провайдер включается при `GOVERNOR_V3_ADVISOR_ENABLED=true` и привязке существующего серверного секрета `RUDN_RECEPTION_OPENAI_KEY`. Код запрашивает GPT‑6.1 Terra через OpenAI Responses с `store: false` и принимает ответ с именем этой модели или её датированного снимка. Таймаут запроса к провайдеру составляет 20 секунд. Локальные проверки используют подставного провайдера.

Модульные тесты из корня репозитория запускаются командой `node --test firebase/functions/governor-v3-advisor/advisor.test.mjs`. Интеграционный тест `emulator-check.mjs` запускается с локальными Auth, RTDB и Functions для `demo-governor-v3`, переменной `GOVERNOR_V3_ADVISOR_MOCK=true` и локальным URL функции в `GOVERNOR_V3_EMULATOR_URL`. Профили и запросы тестовые. Тест проверяет CORS, токен, привязку владельца, вход преподавателя, отказ гостю и обычной учётной записи без профиля, один учтённый вызов при параллельной отправке и запрет прямого чтения приватного хранилища.
