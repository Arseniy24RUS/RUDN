# RUDN Learning Platform — «Введение в специальность: государственное и муниципальное управление»

Статическая GitHub Pages-редакция авторской образовательной платформы Арсения Михайловича Ситковского для студентов РУДН.

## Состав

- 8 лекций и 8 семинаров;
- видеолекции YouTube/VK и презентации PDF/PPTX;
- 195 тестовых вопросов на русском, английском и китайском языках;
- live-квиз «Ветви и уровни власти» с 50 иллюстрированными органами;
- географический конструктор: 89 субъектов РФ, муниципальные образования всех 89 субъектов, страны мира и ADM1 зарубежных государств;
- задания по системе расселения, нормативным правовым актам, обращениям граждан и государственной службе;
- интеграция симулятора губернатора и профориентационного теста;
- электронный журнал до 100 баллов.

## Архитектура GitHub Pages

`site/` содержит полностью статический HTML/CSS/JavaScript-клиент. Профили, попытки, оценки, live-сессии и загруженные подтверждения синхронизируются через Firebase. При недоступности Firebase платформа переходит в локальный режим браузера.

## Публикация

На Windows достаточно распаковать проект и запустить `publish_to_github.bat`. Сценарий создаёт Git-репозиторий, отправляет все файлы в `Arseniy24RUS/RUDN` и, при наличии авторизованного GitHub CLI, автоматически включает GitHub Pages. Workflow `.github/workflows/deploy-pages.yml` публикует каталог `site/` после каждого push в `main`.

Адрес после первого успешного workflow: https://arseniy24rus.github.io/RUDN/

## Firebase

Проект подключён к `russian-regions-puzzle`:

- Anonymous и Email/Password включены;
- правила Realtime Database и Cloud Storage опубликованы;
- Storage-бакет `russian-regions-puzzle.firebasestorage.app` создан в `US-EAST1`;
- загрузка подтверждений до 12 МБ проверена из клиентского приложения.

Firebase Authentication-пользователь преподавателя `omnistat@yandex.ru` создан; пароль известен только преподавателю и не хранится в репозитории. Ограничение Firebase API key и App Check рекомендуется настроить перед массовой эксплуатацией.

Для развёртывания правил на Windows добавлен `configure_firebase.bat`. Подробности: [DEPLOYMENT.md](DEPLOYMENT.md) и [SECURITY.md](SECURITY.md).

## Важное ограничение

GitHub Pages публикует клиентский код и учебный банк как статические файлы. Поэтому ключи тестов технически доступны пользователю, умеющему анализировать исходный код. Эта редакция подходит для формирующего оценивания и учебной работы, но не должна считаться защищённой экзаменационной системой без доверенного серверного контура.
