# Образовательная платформа РУДН

Собственная веб-платформа курса **«Введение в специальность: государственное и муниципальное управление»**.

## Публичная версия

После успешного выполнения workflow сайт публикуется по адресу:

`https://arseniy24rus.github.io/RUDN/`

Платформа содержит восемь лекций, восемь семинаров, трёхъязычный интерфейс, тестовый движок, электронный журнал в 100-балльной модели и встроенные интерактивные приложения:

- пазл регионов России;
- симулятор губернатора;
- профориентационный тест для будущих государственных и муниципальных служащих.

При сборке GitHub Actions извлекает доступные банки вопросов и изображения из сохранённых публичных Яндекс.Форм и включает их в неизменяемый Pages-артефакт. Списки ФИО и групп из прежних форм не переносятся.

## Существенное ограничение GitHub Pages

GitHub Pages является статическим хостингом. Поэтому текущая Pages-редакция сохраняет профиль, попытки и оценки в браузере конкретного пользователя. Для единого электронного журнала всего потока, серверной проверки ответов, загрузки работ и live-квиза потребуется отдельный backend. Исходная серверная редакция платформы остаётся архитектурной основой такого контура.

Кроме того, правильные ответы нельзя надёжно скрыть в публичном JavaScript/JSON. До подключения серверной проверки Pages-редакцию следует использовать для учебных материалов, тренировки и апробации интерфейса, но не для защищённого итогового контроля.

## Структура оценки

- 8 лекций × 5 баллов = 40;
- 8 семинаров × 5 баллов = 40;
- экзамен = 20;
- максимум = 100.

## Развёртывание

Workflow `.github/workflows/pages.yml`:

1. собирает статическую платформу;
2. подключает три существующих интерактивных приложения;
3. восстанавливает доступные вопросы и изображения Яндекс.Форм;
4. проверяет структуру курса и JSON;
5. включает и обновляет GitHub Pages.
