# Проверка сборки GitHub Pages

Проверена статическая версия 1.0.7-pages.

## Автоматические проверки

- синтаксис всех JavaScript-файлов (`node --check`);
- существование всех локальных `src`, `href` и ES-module imports;
- наличие обязательных DOM-элементов, используемых игровым движком;
- 195 вопросов в банке;
- 89 муниципальных карт;
- 50 фотографий органов в Семинаре 1;
- наличие символа у каждой из 50 карточек (часть знаков повторно используется для территориальных органов одного ведомства);
- целостность ZIP-архива;
- размер опубликованного каталога — около 206 МБ, что ниже лимита GitHub Pages в 1 ГБ.

## Браузерная проверка

Проверка выполнена в локальном preview через встроенный браузер. Подтверждены:

- корректный desktop-dashboard;
- 8 карточек тем;
- лекционная страница и тест из пяти вариантов;
- фотография, символ и матрица 3×3 в Семинаре 1;
- английский мобильный интерфейс;
- отсутствие горизонтального переполнения на 390×844;
- отсутствие JavaScript page errors в проверенных сценариях.

## Firebase

В действующем проекте `russian-regions-puzzle` подтверждены:

- анонимная Firebase Authentication;
- наличие Email/Password-учётной записи преподавателя `omnistat@yandex.ru`;
- синхронизация профиля, попытки и лучшей оценки с Realtime Database;
- защищённая загрузка изображения в Cloud Storage;
- сохранение URL подтверждения в попытке;
- отображение результата Семинара 6 в электронном журнале;
- отсутствие ошибок и предупреждений приложения после завершения синхронизации.
