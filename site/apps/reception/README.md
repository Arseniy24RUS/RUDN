# Приёмная · 1.0.1

Нативный модуль семинара 6 «Обращения граждан». Основной маршрут сохраняет идентификатор `#activity/seminar-5`. `renderReception` монтирует `mountReception` в DOM страницы курса; iframe не используется. Шапка, навигация, профиль, расписание и журнал принадлежат платформе.

Обучение не выставляет оценок. Студенческая самостоятельная работа включает восемь дел и передаёт результат от 0 до 5 через существующий `backend.saveAttempt`: тип `citizen-reception`, активность `seminar-5`, стабильный идентификатор попытки. Платформа сохраняет лучший результат и синхронизирует локальную очередь. Преподаватель работает в режиме просмотра без записи рабочих оценок. Авторизация, Firebase SDK и правила базы не изменяются модулем.

Содержание: 178 сюжетов, 356 датированных вариантов и 624 документа. Иллюстрация E13 включена в материалы дела. Новая смена использует опубликованный календарь; уже начатая сохраняет свои даты, материалы и правила оценки. Ежедневная задача Pages обновляет календарный пакет, сохраняя предыдущую проверенную копию при недоступности источников.

Версия 1.0.1 добавляет корректную очистку при уходе из раздела, отмену открытых подтверждений, безопасный повтор загрузки календаря и адаптацию к ширине области курса. Начатые смены схемы 16 сохраняются без пересчёта.

`platform.css` строится командой `python scripts/build-reception-native-css.py`: те же адаптивные правила применяются к ширине контейнера, с учётом закреплённой шапки курса. После изменения исходных модулей автономная копия пересобирается командой `python scripts/build-reception-demo.py`. `demo.html` остаётся вспомогательной автономной тренировкой без записи оценок; курс открывает нативный маршрут.

Интерфейс и сценарии доступны на русском, английском и китайском. Оригиналы нормативных актов в читалке показываются на русском. Читалка использует код семинара 4 и загружает тексты по запросу. Каталог хранит версии актов и SHA-256 пакетов, закреплённых за коммитом в ветке `codex/reception-legal-documents`. Переключение языка оболочки сохраняет ответы. Клиентское оценивание предназначено для учебного практикума и не является защищённым экзаменационным сервисом.
