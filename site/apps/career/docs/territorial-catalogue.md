## Сопоставление с интересами студента

Ранжирование использует существующую девятишкальную модель и её числовые профили карьерных направлений. Для дополнительных органов назначены редакционные функциональные группы по сохранённым описаниям и опубликованным функциям. Ранее подготовленные группировки сохранены; недостающие группировки получены открытыми правилами, приведёнными в скрипте сборки. Наименования помогают уточнить предмет деятельности только при наличии подтверждающего содержания в описании.

Вес направления остаётся учебным коэффициентом. Он не обозначает долю сотрудников, юридическую компетенцию органа, психологическую норму кандидата или минимальный проходной балл. Федеральные условия труда, требования к стажу, образованию и допуску в региональные записи не переносятся; неизвестные условия сохраняются неизвестными.

Полный источник описания, дата наблюдения, ограничения исходного материала и происхождение функциональной группировки сохранены в развёрнутых карточках. Лёгкий каталог содержит первое законченное предложение описания и ссылку на источник. Остальные абзацы доступны в файле карточек соответствующей территории.

## Материалы должностей и вакансий

Для подключения подготовлен 791 материал по 204 работодателям: 328 опубликованных объявлений с неподтверждённым текущим приёмом, 220 архивных вакансий и 243 должностных либо кадровых профиля. Объявления о кадровом резерве и должностные регламенты отнесены к профилям должности. Они не объявляются открытыми вакансиями.

Материалы содержат 8752 исходных строк требований; у 7892 строк в переносимом наборе сохранён положительный признак selfAssessmentEligible. Нормализатор интерфейса устраняет точные повторы в пределах одной карточки и оставляет предпочтительные условия без обязательной оценки. В результате интерфейс получает 8716 уникальных строк, из них 7847 пунктов для самооценки. Все 791 карточки содержат хотя бы один такой пункт. Среди требований отдельно представлены образование, стаж и формальные условия. Эти числа относятся только к дополнительному набору, без изменяемой ленты федерального портала и материалов, добавленных студентом. Число пунктов требований не является числом профессиональных компетенций.

Сохранены исходные формулировки, категория источника, место в документе, ссылка, дата и явные ограничения. Условные альтернативы образования и стажа остаются целыми фрагментами: дробление не должно превращать альтернативы в дополнительные обязательные требования. Отсутствие опубликованного условия отличается от прямого указания, что условие не требуется. Общие отсылки к неуказанным актам и навыкам, спорные или нераскрытые пункты остаются доступными для чтения и уточнения без оценки освоения. Подтверждённые редакционные классификации сохраняют classificationProvenance.

Для 606 исходных строк адрес evidenceSourceUrl отличается от главной ссылки карточки: проверять такую формулировку следует по ссылке самой строки. В двух материалах классификация оцениваемых компетенций полна и имеет статус reviewed; для остальных интерфейс показывает покрытие исходных групп требований. Отсутствующие предметные классификации не достраиваются автоматически.

Текущие объявления федерального портала могут загружаться прежним механизмом платформы. Настоящий набор предоставляет дополнительные источники для изучения требований; поле currentRecruitmentVerified во всех его карточках равно false. Студенческая самооценка не меняет статус исходного объявления.

## Загрузка и формат

territorial-authorities.json содержит компактный индекс и общие числовые шаблоны. expandTerritorialCatalog из assets/territorial-catalog.mjs преобразует его в формат прежнего ранжирования. Размер первоначальной загрузки каталога составляет менее 3 МиБ. Полные описания загружаются по detailPath; файл содержит authorities с точными идентификаторами работодателей.

sourced-position-materials.json служит небольшим указателем. В нём находятся national, regions и total. Каждая запись указывает path и count; региональная запись также содержит regionId. selectedPositionMaterialShards выбирает национальный файл и файлы только отмеченных территорий. Файл материалов содержит positions. При пустом выборе территорий загружается только национальная часть.

## Воспроизведение сборки

Скрипт использует Python 3 и стандартную библиотеку; сеть и полный накопительный архив для выполнения сайта не нужны. Для повторной сборки требуется исходный архив с точным именем `RUDN_Career_v9_Stage5_2026-11-02.zip`. Его SHA-256: `e7f9a33165acc3dc6e1ef3610df6703bece72eefc304ba41b04824bb61649b3f`. Более поздние пакеты `RUDN_Career_v9_Checkpoint_0542_2026-11-04.zip` и `RUDN_Career_TRANSFER_START_2026-11-04.zip` содержат сведения о передаче работы; дополнительные массивы работодателей и требований из них не подменяют перечисленные ниже входы.

Достаточно извлечь из Stage5 три файла, сохранив внутренний каталог `career-update-v9`. Пример выполняется из корня репозитория; пути `../inputs` и `../catalog-source` можно заменить собственными:

```python
from pathlib import Path
from zipfile import ZipFile

archive = Path("../inputs/RUDN_Career_v9_Stage5_2026-11-02.zip")
destination = Path("../catalog-source")
members = (
    "career-update-v9/data/completion/assembled/institutions.json",
    "career-update-v9/data/completion/assembled/positions.json",
    "career-update-v9/data/functional-families.json",
)
with ZipFile(archive) as package:
    for member in members:
        path = destination / member
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(package.read(member))
```

После извлечения команда из корня репозитория имеет вид:

```sh
python3 scripts/build-career-territorial-catalog.py --source ../catalog-source/career-update-v9
```

Значение `--source` указывает непосредственно на каталог `career-update-v9`, внутри которого расположен `data`; это не путь к ZIP и не путь к `data`. Дополнение Москвы находится в репозитории: `site/apps/career/data/territorial-supplement.json`. Сборщик также читает сохранённый базовый каталог `authorities.json` и уже готовый справочник `territories.json`. Перечень территорий включён в обновление как отдельный проверенный вход: этот скрипт не перестраивает его. Его первоначальные ru-идентификаторы получены из `career-update-v9/data/regions.json`, а связь с геометриями и переводы — из `site/assets/puzzle/data/russia_subjects_89.topojson`.
