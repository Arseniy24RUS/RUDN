# Модель Stage 8: определения, расчёт и ограничения

Версии: модель/анкета 8.0.0; реестр ru-public-careers-2026-09-05-stage8.

## Сохранённый предмет

Рекомендации реальных российских учреждений для знакомства студентов ГМУ с возможными направлениями труда. ТОП-5 сохраняется; никаких выводов о квалификации или праве занимать должность по результату теста не делается. Язык интерфейса не является признаком гражданства.

## Измеряемые входы

27 положительно сформулированных задач; девять средних 1–5; по три пункта на шкалу. Приоритеты четырёх из 14 сфер получают 1; 0,82; 0,66; 0,50. Две менее интересные сферы — 0,08 и 0. Остальные — 0,25. Эти веса авторские.

Четыре готовности к условиям оцениваются 1–5. Дополнительно можно уточнить предмет в не более чем двух первых поддерживаемых приоритетных сферах. Поддержаны EDU, INF, AGR, ENV, FIN и DIG, 27 вариантов в сумме. Предпочтение уточнённого предмета не выводится из гражданства, способностей или места жительства.

Пункты K3, T3 и I3 имеют новые формулировки. Их прежние ответы не переносятся автоматически. Остальная анкета сохранена; непрерывная шкала психологической пригодности не конструируется.

## Плавное соответствие роли

Пусть u — девять средних, x=u−mean(u). Для шаблона карьерной роли v определим y=v−mean(v). При λ=0,65 в исходных единицах 1–5:

```
R = 0.5 + 0.5 (x·y) / (sqrt(||x||² + 9λ²) ||y||)
```

Для постоянного шаблона используется R=0,5. При близких ответах влияние формы профиля плавно стремится к нулю. Флаг широкого профиля SD<0,26 оставлен только для пояснения и НЕ меняет числовой режим.

λ=0,65 — явная инженерная настройка, не оценка на выборке студентов. Для изменения одного вопроса на один балл среднее соответствующей шкалы меняется на 1/3. Норма изменения центрированного вектора равна sqrt(8/9)/3. Норма градиента R не превышает 0,5/(3λ). Поэтому изменение вклада 40R не превышает 3,2233 пункта. Максимум по нескольким направлениям сохраняет эту границу. Итоговая граница относится к неокруглённому индексу при фиксированных сферах, условиях и уточнениях; место может измениться значительно среди равных/близких результатов. Округление может добавить до 0,1 к наблюдаемому различию.

Абсолютный уровень интереса сообщается отдельно. Низкий интерес: максимум девяти средних ≤3 и их среднее <2,5. Одинаковая форма низких и высоких ответов может сохранять тот же относительный рейтинг. Низкому профилю не приписывается профессиональная склонность или готовый план развития.

## Предмет и направления внутри органа

Каждый из 334 основных links содержит собственные сферы, темы и условия. Для пути S = max_h(preference_h × salience_h × topic_h). Это возможность работать в подходящей области, а не средняя доля всех полномочий ведомства.

При выбранной теме topic=1 для совпадающей темы, 0,70 при иной явно кодированной теме и 1 при широкой/неописанной тематике. Отсутствие сведений не превращается в запрет. Коэффициент 0,70 авторский и требует дальнейшей содержательной оценки. Максимум устраняет штраф за добавление альтернативной сферы, но способен порождать равенства; они видимы в интерфейсе и отчётах.

Назначение DIG и INT отдельным направлениям отражает выбор предмета цифровой/международной работы. Это модель, а не утверждение, что сотрудник любой организации исполняет полномочия Минцифры или МИД.

## Условия, неопределённость

Значение требования — число, диапазон [a,b] либо null. Null даёт нейтральный вклад 0,5 и в интерфейсе обозначается как неизвестное. Для готовности w и числового требования q: fit=1−max(0,q−w)/4.

Для диапазона используется средний штраф по равномерному авторскому сценарию:

```
Egap = (max(b−w,0)² − max(a−w,0)²) / (2(b−a))
fit = 1 − Egap/4
```

Диапазон не является доверительным интервалом и не описывает распределение вакансий. Четыре fit усредняются. Более высокая готовность не снижает соответствие. Общие авторские диапазоны представлены в data/path-rubric.json; индивидуальные режимные требования и оперативный график в основном реестре оставлены неизвестными. У восьми дополнительных объектов сохранены прежние авторские оценки по отдельным путям; они не являются проверенными условиями вакансии.

## Итог и равенства

```
pathScore = 100 (0.40 R + 0.45 S + 0.15 C) × presenceFactor
presenceFactor = 1.00 для 3; 0.96 для 2; 0.91 для 1
agencyScore = max(pathScore)
```

Фактор представленности — порядковая авторская гипотеза, не процент персонала и не число вакансий. Сортировка использует исходный неокруглённый индекс; округление до десятой — только представление. При точном равенстве технический порядок определяется идентификатором. Выбор первого отображаемого органа внутри равенства не имеет содержательного преимущества. В интерфейсе раскрываются равные лидеры и равные пятому результаты за границей пятёрки.

Статистика лидеров группы распределяет 1/n между n равными лидерами. Выгрузка отдельных результатов по-прежнему хранит отображаемый ТОП-10; поля first_displayed_authority и equal_leading_authorities разделены. Статистика отображаемого ТОП-5 зависит от технической границы — не трактовать её как долю уникальных предпочтений студентов.

«Неочевидный вариант» выбирается только с мест 6–20 при familiarity≤3, отставании от пятого результата≤9 и S≥0,28. Нет кандидата — нет блока. Familiarity остаётся авторской оценкой известности, не результатом опроса аудитории.

## Что проверки не доказывают

Ни 15 000 синтетических анкет, ни 334 правильно оформленных link, ни модульные проверки не являются психометрической валидацией. Известные ограничения: общие шаблоны порождают частые равенства; предметные уточнения не покрывают все отрасли; подготовка/география/юридическая доступность должности не измеряются; русская, английская и китайская формы не проверены на межъязыковую эквивалентность. Использовать в учебном обсуждении, не в кадровом отборе.
