# Подключение модуля к диагностике и обновлениям

Оболочка передаёт модулю диагностический контекст, закреплённый за текущим профилем и модулем. Используйте `diagnostics.record(event, fields)`, `diagnostics.error(error, {operation})` и `diagnostics.span(operation)`. Последний возвращает функцию завершения с `success` и длительностью. События содержат технические идентификаторы, но не ответы, поля форм, запросы поиска, сообщения исключений или тела HTTP-запросов. Ошибки из `catch` следует явно передавать в этот контекст. Не используйте `console` как транспорт журнала.

Самостоятельный вход получает общий экземпляр через `getSharedPlatformDiagnostics`. После определения профиля создаётся `forModule(name)`; он фиксирует владельца. Отложенные операции сохраняют этот объект, а не получают новый контекст при завершении. При смене профиля старый экземпляр модуля закрывается. Название модели устройства не вычисляется из размера экрана.

Адаптер модуля предоставляет `prepareForUpdate`, `resumeAfterUpdate`, `cancelPreparation`, `commitPreparation` и `module`. Общая реализация — `createUpdateAdapter` в `platform-update-state.js`. Оболочка не принимает `flush()` за доказательство сохранения.

`checkpoint` снимает последние значения, включая поле без blur, дожидается завершения очередей и возвращает `{durable:true, revision, checkpointRef}` только после подтверждённой локальной записи. Конфликт, неподтверждённое вложение, чужой writer или ошибка хранилища запрещают переключение. Сеть может отсутствовать, если работа и очередь доставки надёжно сохранены на устройстве.

`capture` возвращает состояние интерфейса: режим, вопрос, документ и якорь, панели, камеру, инструмент и неподтверждённое действие. Учебные ответы остаются в штатном черновике. `restore({state, checkpointRef, identity, revision}, {signal})` восстанавливает существующую попытку и интерфейс; не создаёт попытку, не отправляет результат и не подтверждает предпросмотр. Асинхронные шаги должны проверять отмену и владельца после ожидания.

`pause(true)` временно останавливает изменения, сохраняя предпросмотр. `pause(false)` снимает паузу, в том числе после неудачной подготовки. Общий предел подготовки — пять секунд. `commitPreparation()` оставляет локальный пакет для нового документа; обычная отмена удаляет незавершённый пакет. Уход с маршрута должен дождаться освобождения подписок и writer старого модуля.

Версии контрактов заданы в `site/data/platform-contracts.json` и включены в проверяемый манифест выпуска. Несовместимый контракт откладывает обновление до появления явной миграции. Версия контракта восстановления не заменяет версию правил игры.

Координатор объединяет проверки выпуска при запуске, открытии модуля, возвращении из фона и сети, а также каждые пять минут видимой работы. Он проверяет ресурсы, сохраняет пакет, делает один переход и подтверждает запуск после восстановления. Не добавляйте в модули собственные `location.reload()` для обновления версии. При ошибке восстановления допустим один возврат на проверенный предыдущий runtime; затем показывается восстановительный экран без выхода из профиля.

Неудавшаяся immutable-сборка фиксируется в отдельном локальном ограниченном списке до очистки браузерного хранилища. После успешного отката новый документ не пытается снова запустить ту же сборку; следующая сборка с другим build ID допускается. Ранний bootstrap и координатор используют общий `platform-update-failures.js`. При недоступном или повреждённом списке автоматическое переключение откладывается; учебная работа продолжается. Если после отката невозможно надёжно записать этот признак, пакет восстановления сохраняется и остаётся восстановительный экран. Это технический список из 32 последних неудавшихся сборок, отдельный от серверного архива диагностики без автоматического срока хранения.

Первая миграция не перезапускает старые вкладки, которые ещё не имеют координатора. Автоматические обновления действуют после штатного открытия новой оболочки. Браузер может потребовать жест для повторного fullscreen или открытия экранной клавиатуры. Проверки браузерных движков не заменяют проверку физических телефонов.
